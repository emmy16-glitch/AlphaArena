# AlphaArena

AlphaArena is a 24/7 AI market laboratory for tokenized U.S. equities.

The product combines three connected experiences:

- **NightWatch** — market intelligence and adversarial trade-thesis stress testing.
- **MarketTwin** — historical and quantitative what-if scenario simulation.
- **Arena** — virtual-capital thesis battles settled against real market prices.

## Hackathon positioning

Bitget AI Base Camp S2 — **AI Trading Desk / Decision Stress-Testing**.

## Product principle

**Predict less. Test more. Let the market decide.**

The AI researches, challenges, simulates and explains. The human remains the final decision-maker. Real-money trading is not required for the core product.

## Architecture

- Frontend: React + Vite, deployed to Vercel
- Backend: Python + FastAPI, intended for Azure
- Market layer: Bitget UTA v3 / Reality rToken market data
- Financial research: Vibe-Trading integration layer
- Reasoning: Qwen cloud API
- Persistence: MongoDB Atlas later

## Current build phase

Version 4 of the AlphaArena UI is the visual source of truth. We are preserving its editorial paper/Swiss financial design system while progressively replacing demo data with real integrations.
